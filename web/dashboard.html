Run an active-learning campaign.

Upload a CSV, choose a surrogate and query policy, and reveal measured affinities over successive cycles.

Local execution only
Browsing works directly from this file. To execute Python models, run python dashboard.py from the proteinlipid folder, then open http://127.0.0.1:8765. Uploads cannot run from a static HTML file.

1. Upload measured pairs

Required columns: protein_sequence, lipid_smiles, affinity.

Use one affinity endpoint, standard amino-acid sequences and valid SMILES. Every affinity must be measured and numeric. Duplicates are rejected after canonicalizing SMILES.

2. Configure the experiment

A frozen 20% random-pair test set is excluded from acquisition. Initial + batch × cycles must fit within the remaining pool (maximum 500 acquired labels). Raw Kd/Ki is converted to pK. Protein composition uses a Matérn 3/2 factor.

This is retrospective AL, not a live experimental oracle. Input data remain on this computer under results/user_runs. New runs produce metrics, query indices and test predictions; SHAP is not automatically computed for uploads.

No benchmark results are overwritten.
